## Stable local HTTP surface

Backend default address: `http://127.0.0.1:8000`. Frontend default port: 5173, with explicit configuration if occupied. Base API path: `/api/v1`. Frontend uses a single configurable base URL and an explicit fixture/live-backend switch. Never silently fall back from a failed real request to fixtures.

- `GET /health` -> `{"status":"ok","contract_version":"0.1"}`. May add service details.
- `GET /api/v1/config/status` -> `{"contract_version":"0.1","provider_mode":"fixture","crustdata_configured":false,"thesis_status":"awaiting_reference","semantic_matcher_configured":false}`. Boolean presence only, never secret values.
- `GET /api/v1/mandates` -> `{"items":[Mandate]}`.
- `POST /api/v1/mandates` with CreateMandate -> Mandate, status 201.
- `GET /api/v1/mandates/{id}` -> Mandate.
- `POST /api/v1/mandates/{id}/run` -> Task, status 202. Bounded work; repeat request must not multiply cases for the same mandate.
- `GET /api/v1/mandates/{id}/cases` -> `{"items":[Case]}`.
- `GET /api/v1/cases/{id}` -> CaseDetail.
- `GET /api/v1/cases/{id}/evaluations` -> `{"items":[Evaluation]}` ordered oldest first.
- `POST /api/v1/cases/{id}/signals` with SignalInput -> CaseDetail. Persist a labeled signal event; any fixture evaluation must remain labeled. A signal alone need not qualify a case.
- `GET /api/v1/tasks/{id}` -> Task.

Errors: `{"error":{"code":"not_found","message":"Readable explanation","retryable":false}}`; use corresponding HTTP status. Additional machine codes include validation_error, provider_not_configured, provider_unavailable, invalid_transition, and stale_version. Do not expose raw secrets/provider payloads in errors.

## Shared shapes

Times: ISO 8601 UTC. IDs: opaque strings. Arrays should be present even when empty. Missing score/value is null, not zero. Scores use 0–1 if populated, with fixture status visible. No probability language.

`DataMode`: `live | captured | synthetic`.

`CaseStatus`: `discovered | enrichment_pending | investigating | needs_evidence | monitor | qualified | outreach_ready | rejected | failed`.

`CreateMandate`: `{title:string, thesis_text:string, target_count:integer, reference_status?:"placeholder"|"user_supplied"}`. Required nonempty text; no invisible default real thesis. Initial reference_status defaults to placeholder until the real thesis is supplied and reviewed.

`Mandate`: `{id, title, thesis_text, thesis_version:integer, reference_status:"placeholder"|"user_supplied", target_count:integer, target_state:"outreach_ready", status:"draft"|"running"|"completed"|"shortfall"|"failed", progress:{total:integer,outreach_ready:integer}, created_at, updated_at}`. User-supplied text is retained exactly; normalized criteria/ambiguities may be additive fields and must not be implicitly approved by text submission alone.

`Person`: `{id, name, role:string|null, profile_url:string|null, source_key:string|null, data_mode:DataMode}`.

`Evidence`: `{id, company_id, claim_type, summary, source_url:string|null, source_key:string|null, observed_at:string|null, retrieved_at, data_mode:DataMode}`. Synthetic examples must not masquerade as source verification.

`Dimension`: `{name, score:number|null, status:"supported"|"contradicted"|"unknown", rationale, evidence_ids:string[]}`.

`Evaluation`: `{id,case_id,thesis_version:integer,created_at,dimensions:Dimension[],thesis_fit:number|null,evidence_sufficiency:number|null,recommendation:CaseStatus,missing_claims:string[],next_action:string,reasoning_summary:string,evidence_ids:string[],data_mode:DataMode,evaluator_kind:"fixture"|"semantic"}`. Fixture evaluator is a development harness, not implemented semantic reasoning.

`Case`: `{id,mandate_id,company_id,company_name,canonical_domain:string|null,status:CaseStatus,version:integer,thesis_fit:number|null,evidence_sufficiency:number|null,next_action:string,why_now:string|null,data_mode:DataMode,updated_at}`.

`Event`: `{id,case_id,event_type,created_at,summary,evidence_ids:string[],replayed:boolean,data_mode:DataMode}`.

`OutreachPackage`: `{person:Person|null,rationale:string,draft:string,readiness_gaps:string[],data_mode:DataMode}`. Never implies sending or a meeting booked.

`CaseDetail`: all Case fields plus `{evidence:Evidence[],evaluations:Evaluation[],events:Event[],outreach:OutreachPackage|null}`.

`SignalInput`: `{summary:string,claim_type:string,source_url:string|null,replayed:boolean,data_mode:DataMode}`. In the initial demo, replayed must be true and data_mode synthetic or captured unless a real provider signal is verified. Server validates combinations; app cannot simply mark arbitrary browser text as verified live evidence.

`Task`: `{id,mandate_id,case_id:string|null,type:string,status:"pending"|"running"|"succeeded"|"failed",error:string|null,created_at,updated_at}`.

## Adapter and configuration seams

Backend chooses Python FastAPI and typed validation; persistent local development storage can use SQLite with a configured DATABASE_URL seam for PostgreSQL. Do not make RabbitMQ/PostgreSQL infrastructure a prerequisite for the first runnable harness. Keep a bounded job-runner interface so execution can later move to Dramatiq without changing HTTP contracts. Document in-process job limitations honestly.

Separate discovery provider, thesis loading, semantic evaluator and state persistence. Default fixture mode runs without external calls. `CRUSTDATA_API_KEY` stays server-side in an ignored local environment file. Explicit live mode with missing credentials returns a configuration error and never synthetic success. Verify actual Crustdata endpoint/filter/auth documentation before implementing request mappings; don't invent API behavior or make credit-consuming calls while access is unavailable.

Reference thesis is editable input/configuration, versioned and independent of the provider key. Record `awaiting_reference` until the user supplies it. A labeled placeholder may support development. Criteria-specific logic and demo scores must not be baked into the framework.

The genuine semantic matching module will come later. Provide an evaluator protocol and labeled fixture evaluator now. Preserve immutable evaluations and unknown dimensions. Do not claim that seeded dispositions are model-generated investment judgments.
