# ThesisOS

A local sourcing workspace that turns an editable mandate into persistent company cases, evidence, assessment history, and a reviewable outreach package.

**Current foundation:** React/TypeScript + FastAPI/SQLite with persistent evidence, genuine prompt0.3 research assessments and source-linked graphs. The prepared workspace contains nine enriched real company cases at version3. Dashboard shows saved pipeline dispositions, company radar, reported work and the separate pre-outreach decision: is an introductory conversation worthwhile? Conversation merit, relevant-person/contact preparation, formal partner-review readiness and human qualification are distinct. A selected company opens one focused case; original model assessments, unresolved questions and attempt history remain inspectable. Canonical thesis v0.3 and the additive pre-outreach overlay can be read in Mandate review.

A bounded continuous-scouting worker is controlled through explicit backend start/status/stop routes and the compact run panel. Its maximum authorized run is30minutes,4new cases,20provider requests,50credits and4model attempts, with1concurrent operation; caps or an exhausted reviewed plan can stop it earlier. The panel reports the actual server state, deadline, confirmed versus reserved credits, stop reason and arriving cases. No run is active merely because the panel or credentials exist. No outreach is sent, qualification accepted or meeting booked. Fixture discovery/evaluation remains an explicit fallback.## Demo journey

1. Open Dashboard in the prepared workspace and select the nine-company product/program mandate. Inspect company radar and the separate current pre-outreach labels and contact-preparation gaps. The formal saved research dispositions remain visible and are not silently requalified.
2. Open NeoTargets: inspect its company/team evidence and introductory agenda, then the preserved formal handoff. Scientific work can justify a conversation while company capability/access and confounder questions remain open. A conversation candidate is not a qualified investment or permission to send.
3. Open Cadex to see the specific current-operator/status question and separately linked report-search versus leadership attempts. Follow a source citation into the ledger; inspect the person-focused research graph and download its full source-bound JSON. Reload to verify the exact company and immutable history.
4. Open Mandate review for the complete canonical thesis, unchanged saved run brief, server source/hash binding and separate pre-outreach overlay. A configured canonical source does not prove every historical assessment input or activate investment qualification.
5. Inspect the bounded live-run panel. When a run is actually started by the authorized operator, follow its deadline, limits, current work, confirmed/reserved credit use and saved case links. View run cases to watch the collection update. Stop requests are cooperative; the current request may finish before the backend reports stopped. Do not start another paid run merely to rehearse saved results.
